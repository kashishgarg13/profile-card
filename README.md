# profile-card

A simple and modern **Profile Card** built using **HTML and CSS**.  
This project showcases a clean card layout with social media links, buttons, and analytics icons.

---

## 🔥 Features

- Clean and modern UI
- Circular profile image
- Social media icons
- Subscribe & Message buttons
- Analytics section (likes, comments, shares)
- Responsive layout
- Google Fonts (Poppins)
- Font Awesome icons

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome
